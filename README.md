# strange-site
# 10日観光案内 (10-Day Sightseeing Guide)



**概要**
Streamlit製のお手軽ホラー・間違い探し脱出ゲームです。8月10日から8月19日までの10日間、観光地ガイドに潜むさまざまな「異変」を見抜き、無事に現実世界への脱出を目指します。

**主な特徴・発生する異変**

* **文章の異変**: 正常な解説文が不気味なホラーテキストに変わる


* **写真の異変**: 観光地の画像が不穏なものに差し替わる


* **観光地名の異変**: スポット名が禍々しい名称に書き換わる


* **訪問者レビューの異変**: 口コミ欄が「助けて」などの悲鳴や脅迫文になる


* **情報欠損の異変**: 説明文や名称が「████」の黒塗りにされる


* **UI・配置の異変**: ボタンの配置が左右反転したり、観光地の順番がシャッフルされる


* **幻のスポット**: 存在しない11個目の不気味な観光地が紛れ込む


* **配色の異変**: システムカラーが血の赤色に染まる



**遊び方**

* アプリを起動し、ルールを確認してゲームをスタートします。


* 10か所の観光地ガイドと訪問者の声を注意深く観察します。


* **異変がある場合**: **「🔄 再読み込みする」** ボタンを押します。


* **異変がない場合**: **「➡️ 次の観光案内へ」** ボタンを押します。


* 選択を誤ると、容赦なく8月10日（1日目）に巻き戻されます。全10日を突破してクリアを目指しましょう。



**動作要件・セットアップ**

* Python 3.x


* Streamlit



```bash
pip install streamlit
streamlit run app_11.py

```
